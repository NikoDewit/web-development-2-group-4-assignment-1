## Description

This project is a browser-based unit converter for weight, distance, and temperature. It converts kilograms and pounds, kilometres and miles, and Celsius and Fahrenheit in either direction. Users can enter multiple comma-separated values; weight and distance values must be positive, while temperature values may be any valid numbers. The calculator validates the entries, applies the relevant conversion formula, and displays each result to two decimal places. A switch control reverses the conversion direction and updates the page labels.

## Implementation

- `index.html` is the home page and links to each calculator.
- `pages/` contains the weight, distance, and temperature calculator interfaces.
- `scripts/` contains the TypeScript source files and the JavaScript files loaded by the calculator pages.
